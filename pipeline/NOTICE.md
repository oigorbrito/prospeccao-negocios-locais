# Origem do código

- `gerador_sites.py`, `horarios.py` e `templates/site.html` foram adaptados do gerador do projeto
  **webbiz** (https://github.com/oliverdadude/business-websites). O uso do código foi autorizado pelo
  responsável deste projeto. O repositório de origem não traz arquivo de licença.
- Mudanças em relação ao original: textos em português do Brasil; remoção de todos os textos de serviços,
  sobre a empresa, avaliações e diferenciais (o original os inventa); a fonte dos dados passou a ser um CSV
  (sem banco de dados e sem envio de e-mail).
